N5 必考 7 大核心助詞解析

は (wa) 主題標記

提示全句的主題，讀音讀作「わ (wa)」。

わたしは学生です。(我是學生。)
が (ga) 主語 / 存在標記

強調特定主語，或搭配「能力/喜好/存在動詞」。

猫がいます。(有貓咪。)
を (o) 目的語標記

標示他動詞作用的對象或動作。

水を飲みます。(喝水。)
に (ni) 時間 / 目的地 / 靜止點

用於具體時間點、目的地或存在位置。

7時に起きます。(7點起床。)
で (de) 動作場所 / 工具手段

標示動作發生的地點，或使用的交通工具/工具。

バスで行きます。(搭公車去。)

N5 入門基礎句型整理

1. N1 は N2 です / ではありません

肯定與否定句：N1 是 N2 / N1 不是 N2。

例：これは本です。(這是書。)
例：これは本ではありません。(這不是書。)
2. 存在句：あります vs います

「無生命物」使用 あります；「有生命物(人/動物)」使用 います。

例：部屋に机があります。(房間裡有桌子。)
例：庭に犬がいます。(庭院裡有狗。)
3. 動詞 ます 形時態變化

叮嚀體禮貌形：現在肯定/否定、過去肯定/否定。

• 肯定：食べます (吃)
• 否定：食べません (不吃)
• 過去肯定：食べました (吃了)
• 過去否定：食べませんでした (沒吃)
